# KGFM COF Demo

This repository contains the demonstration materials for our BESC 2026 paper, **Knowledge-Driven Intelligent Design Assistant for Covalent Organic Framework Materials**.

The demo presents an interactive AI-for-Science prototype for knowledge-guided covalent organic framework (COF) research. It shows graph-based COF question answering, COF design analysis, monomer library exploration, and interactive 3D molecular visualization.

The companion demo video for the paper is [2026 BESC demo video.mp4](https://github.com/Modelen530/BESC-2026-cof-demo/blob/main/2026%20BESC%20demo%20video.mp4).
